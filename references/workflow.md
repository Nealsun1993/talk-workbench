# 从文案到交付

依据作者 2026-10-13 确认的口播规范整理，v1.2 补上 2026-10-23 前实际出片的做法。以下是可替换的工具分工，实际生成能力取决于使用者环境与授权。

| 环节 | 分工 |
| --- | --- |
| AI agent | 串联资料、确认稿、时间轴、素材和版本 |
| video-talkcraft（可选） | 分镜、词时间、动效参考与制作检查；不是 TTS 引擎 |
| VoxCPM 或已有配音 | 声音生成或音频输入；参考声音必须本人或获授权 |
| 解说生图 Skill + 实际图像工具 | Skill 约束角色、构图和画风，图像工具真正出图 |
| Omni（按需） | 使用用户指定的平台和模型，将确认首帧变成短动作 |
| talk-workbench / Remotion | 场景、工作台、准确文字、字幕与合成 |
| FFmpeg / ASR | 音视频处理、实际词时间和检查；ASR 不等于人耳试听 |

## 0. 写稿之前（v1.2）

先回答三句话，写在稿子最上面；答不出来就先改选题角度：

1. 观众看完能自己做出什么（"用你喜欢的歌做一支自己的 MV"，而不是"认识一个工具"）。
2. 钩子是什么：资料包里装什么，评论区留哪个口令。资料包只放自己做的东西，别人的工具只介绍、标来源。
3. 第一句点名了谁：点名一类人，口气往大里写，一听就懂；功能、数字、效果仍按实测写。

节奏拖沓时先删稿子：换声音、调语速都不会让内容变短。

## 1. 先确认文案和声音

保留原稿与最新确认稿；稿子较长时先报告实际预计时长，不强行加速来满足“短平快”。不恢复用户删掉的结尾。

先试含工具名、数字、英文和长句的完整短段，再生成整稿。按完整语义段生成，避免一句话拆成两段留下硬停顿。屏幕写准确名称，发音辅助拼写仅用于声音输入；网址展示即可，除非明确要求逐字朗读。

只调整静音时先定位波形和上下文，保留自然呼吸；误读、漏字则重做完整短句。

逐句生成时每句单独转写一遍核对：多音字（「去重」念成 zhòng）在发音辅助表里写同音字；英文缩写写成逐字母读音；可疑的句子换一个随机种子重配。同一句换几个种子转写都一样"错"时，常常是转写偏差，要用人耳确认，不要无限重配。修改声音后统一更新字幕、镜头、重点动作与章节时间。保留实际音频和字词对齐来源，不把估计秒数当作真实词落点。

## 2. 图片、角色与动画

优先真实页面、作者示例和已有成片，通常每个环节选择 2–3 张有区别的图片；复杂概念才用插画比喻。画面放大到可读，保护字幕与平台覆盖区。

固定角色必须使用认可的参考图，保持外形、颜色和身体比例。作者的莱恩是个人角色示例，不随公共包提供；使用者可替换为自己的角色。机器人互动只在本期需要时加入。

需要动画时：选择一个核心动作 → 制作起始瞬间首帧 → 检查角色与手/道具接触 → 在已授权的入口提交 → 保存任务号 → 连续播放检查 → 对齐解说。按准备、执行、结果、停稳描述动作；文字、Logo、精确数字与工具图标优先在后期制作。

交接时让动画一方写一份说明：画面宽高、帧率、时长，屏幕或空白牌面在画面里的位置（像素框），以及实际看到的动作时间点。后期按位置往屏幕里放视频、往空白牌面上叠字（`film.screen`、`film.labels`），按动作时间点对齐配音；素材比镜头短时停在末帧，不慢放。生成画面里一个字都不要有，字一律后期叠。

沿用已确认的入口与授权，不猜同名服务的接口。状态不明先查询现有任务，避免重复付费。接口失败如实说明；不能把静态缩放标成角色表演完成。通常关闭生成片段自带音轨，沿用已确认配音。

不靠倒放、反复循环或极端慢速硬凑片长；动作节点对不上时重新分镜或拆段。白底、绿幕或透明合成按本期需求选择；抠像未验证不得承诺效果。

## 3. 样片、返修与发布

先交带声音的样片，确认风格、字幕大小、角色比例和节奏后继续全片。单期明确选择优先于默认方案 D。修改按时间点定位，保留改前版本，受影响配音变化后统一重排全部后续时间。

默认不在顶部烧常驻导航，工作台标签只用于正文；章节时间单独交付。字幕统一简体并上移，平台遮挡以实际手机显示为准。

最终 AAC 测量 −14.5 LUFS 目标、−15～−14 LUFS 范围、≤−1 dBTP 真峰值；中间 WAV 读数不能替代最终文件。用户连续试听和手机 A/B 未完成时，交付标为审看版。

## 4. 封面与分享包

作者系列默认竖版 9:16、深蓝底、亮蓝信息卡、橙红强调、原版黑白立绘。立绘不能重新生成五官；公共复用时提供自己的品牌素材。横版发布按实际裁切参考安排中心内容和两侧背景延展，保持图片和文字比例，不横向拉伸。

交付目录可包含：成片、字幕、章节、封面、发布文案、可编辑工程和素材来源。分享给粉丝的材料分为“给人看的风格/工具说明”与“给 AI 的安装和使用说明”。安装说明只指向工具入口，说明哪些另需模型或账号，不宣称一份 skill 已包含全部服务。

工具参考入口：[video-talkcraft](https://github.com/Vincentwei1021/video-talkcraft)、[VoxCPM](https://github.com/OpenBMB/VoxCPM)、[Remotion](https://www.remotion.dev/)。分别查看许可；不因本仓库是 MIT 就认为外部工具也可任意商用。对外文件不附私人声纹、API 密钥、公司私有素材或未授权的第三方安装包。
