# 动效规范

一句话：**每个动作都对应配音里的关键词；动作到位后保持可读，再以有意义的下一步推进。**

## 光标

只做三种有意义的动作：

| 动作 | 什么时候 |
|---|---|
| 点击 | 按钮、开关、勾选、标签、列表行 |
| 悬停滑过 | 沿着被聚光的那句话滑过去 |
| 拖拽 | 把文件拖进来 |

- 点击时光标缩一下，并出一圈蓝色涟漪。
- 默认开启悬停反馈、略带弧度的路径和点击前约 0.16 秒到位；按钮先亮起或抬起，再按下。开关刚开启时有短暂亮度变化。旧工程可用 `"motion": {"polish": false}` 关闭打磨。
- 动作之间停住不动，不做无意义的漂移。
- **工作台路径由页面模板根据 props 算出**，仍需实际检查落点。scene 光标由配置给出坐标，必须对照关键帧核对。

## 相机

像录屏软件的自动跟随：说到哪块推近哪块，讲完拉回整窗。

- 推近倍数 1.1 到 1.45。
- 每次移动 0.8 秒，两头慢；比焦点提前 0.1 秒起步，有跟随感。
- 一个镜头最多推近两次。推近后必须拉回来，不能停在半截。
- 可用 `zoom: false` 关闭推近；不做镜头慢呼吸或慢推填时长。大纲全片完整展示一次，回大纲最多一次。

## 换页：优先承接

**承接** = 上一页里被点的、被说到的那个元素，直接长成下一页（0.55 秒）。

- 旧页原地不动，旁边的内容在新页长大时淡掉，不留残影。
- 例：点模块行 → 行展开成浏览器页；原文卡片 → 长成能力清单；通知条 → 长成时间轴；时间轴面板 → 长成合成页。
- 找不到合适的元素时，才用默认方式：旧页左移淡出，新页从右推入。
- **工作台内至少一半的换页优先承接。** scene 间默认退出再进入，暂不自动对象承接；详见 [scheme-d.md](scheme-d.md)。

写法：下一镜的 props 里加

```json
"carry": {"anchor": "item:0", "click": true}
```

`click: true` 表示光标先点一下这个元素，它随即长成新页；不写就直接长。各页可用的锚点见 `templates.md`。

窗口启动同理：会话第一镜写 `"launch": {"from": [x, y, w, h], "r": 22, "bg": "#CFE2F6"}`（画面坐标），窗口从这个区域长出来。

## 动作曲线：不同动作用不同曲线

全片用同一个缓动，画面会显得「软」。分工如下：

| 动作 | 曲线 | 时长 |
|---|---|---|
| 点击、开关、勾选、状态变化 | 快速到位（expo 缓出） | 约 0.22 秒 |
| 行、卡片、通知出现 | 带一点回弹的弹簧（超出约 4%） | 约 0.4 秒 |
| 镜头移动 | 两头慢的 S 曲线，提前 0.1 秒起步 | 0.8 秒 |
| 承接变形 | expo 两头，起步干脆、落位稳 | 0.55 秒 |
| 标题、说明文字 | 平滑出现，不回弹 | |

## 运动模糊

- 引擎目前只对 **工作台** 的承接、换页、镜头移动自动加 180° 快门运动模糊（6 次采样）。
- `orb` 球飞行和 `scene` 快速流入流出尚未接入自动模糊。若本期要求这些段落有模糊，需要补充实现或预渲染，不能把工作台开关当作全片覆盖。
- 静止帧不加，保持清晰。
- 目的是让快速移动不再一格一格地跳。
- 默认自动开启；不需要时在 episode.json 顶层写 `"motionBlur": false`。

## 时间锚点

- 每个 `at` 是配音里关键词的时间，从骨架的 `_words` 查。
- 关键词出现的那一刻，对应动作同时发生。
- 不手敲近似秒数：差零点几秒，观众就能感觉到「画面抢了」或「画面慢了」。
