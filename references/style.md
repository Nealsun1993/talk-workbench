# 视觉规范

画布 1080×1920（竖屏），30fps。画面跟着配音的字级时间走。默认方案 D：概念场景和工作台按讲解内容交替，窗口仅在连续 app.* 镜头中常驻。

## 颜色：一种颜色只表示一件事

| 名称 | 色值 | 只用于 |
|---|---|---|
| paper | `#F6F8FC` | 全片底色 |
| ink | `#10243A` | 信息文字、通知条（对比度 14.8:1） |
| secondary | `#56677C` | 次要文字（5.45:1） |
| voice（亮蓝） | `#285BF0` | 工作台中为 **当前 / 正在操作的**：选中的标签、打开的开关、主按钮、聚光框、点击涟漪、当前时间块 |
| problem（橙红） | `#FF795C` | **问题 / 痛点**，以及行动号召 |
| navy | `#0B192F` | 只用于深色结尾 |

方案 D 的场景和大纲里，蓝色只作荧光笔；黑色表示选中或强调。工作台的蓝色仍表示当前操作。完整场景与大纲规则见 [scheme-d.md](scheme-d.md)。

## 字号：5 档，最小 32px

| 档 | 字号 / 字重 | 用在 |
|---|---|---|
| display | 76 / 600 | 大标题 |
| heading | 52 / 600（窗口页标题 56） | 页面标题 |
| body | 40 / 500 | 正文、行名称 |
| caption | 32 / 500 | 说明、标签 |
| subtitle | 46 / 600（超过 18 字用 42） | 字幕 |

- 字体 MiSans；数字、网址、时间码用 JetBrains Mono。
- 32px 约等于手机上的 11.6pt，再小就读不清。
- **配音念到的字，在画面上不小于 32px**（字号 × 相机倍数）。

## 窗口

- 位置 x 72–1008、y 170–1380，圆角 36，白底，柔和大阴影。
- 标题栏：三个灰点，中间是 App 名（默认「口播工作台」，可用顶层 `app.title` 改），右侧**常驻「示意界面」标签**。
- 标签栏 = 本期章节（`chapters` 里带 `tab` 的项），章节多时自动收窄，最多约 8 个。换章时光标去点对应标签，白色滑块移过去。
- 这是讲解用的示意界面，**不冒充任何真实软件**：不用真实产品的名字、Logo、配色。

## 背景

- 纸色底上一层点阵（间距 40，上淡下浓），一束很淡的蓝光在下半部慢慢游走（周期 19 到 28 秒），光扫过的点微微变蓝。
- 相机推近时点阵只跟着推近约五分之一，形成轻微视差。
- 背景不承载信息，不用橙色。
- **窗口下方约 400px 是平台文案和昵称会盖住的区域，只放背景，不放内容。**
- 写法：episode.json 顶层 `"backdrop": {"kind": "grid"}`。

## 字幕

- 从 y = 1455 开始，左右 x 80 到 960（右边留给平台按钮）。
- 简体中文，工具名写准确。素排，不加动效。
- 1455 是这套版式的参数，不是所有平台通用的安全线，**发布前要在手机上实看**。

## 真实与示意

| 内容 | 怎么处理 |
|---|---|
| 真实页面（GitHub、官网、文档） | 放进内置浏览器（`app.browser`），网址栏写真实地址，标「xxx 实际页面」 |
| 关键句 | 聚光（压暗其余、蓝框框住），再抬成原文卡片，原文照抄，标来源 |
| 波形、时间轴 | 用本片真实的配音数据 |
| 样图、成片 | 标 `作者示例` / `既有成片 · xxx 节选` / `自制示意` |
| 进度条、按钮状态 | 属于示意，由标题栏「示意界面」说明 |

没有实测，不演「测试通过」。

## 不要做

- 不加贯穿全片的装饰线（包括底部声音线条、引线、收束线）。
- 不整屏淡出再淡入；不加漂浮圆；背景不做快速或有形状的动画。
- 同一屏不放两个焦点。
- 不把整页截图缩小塞进去却不聚光。
- 底部不常驻品牌签名；不给非步骤内容加 01 / 02 / 03 编号。
