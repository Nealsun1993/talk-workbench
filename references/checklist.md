# 验收清单

出联系表（`bash scripts/contact.sh <期名> <秒> …`）后逐项看。渲整片后再过一遍后四项。

## 画面

- [ ] 每屏只有一个焦点。
- [ ] 所有文字不小于 32px；被配音念到的原文，在画面上不小于 32px（字号 × 相机倍数）。
- [ ] 标题栏的「示意界面」可见。
- [ ] 每个素材都有真实性标签；原文卡片里的字和原文一致。
- [ ] 蓝色只出现在「当前 / 正在操作的」上；橙色只出现在问题和行动号召上。
- [ ] 背景只有点阵和慢速游走的蓝光；没有贯穿全片的装饰线，没有漂浮圆，没有整屏淡出淡入。
- [ ] 窗口下方约 400px 没有放内容。

## 动效

- [ ] 光标每次点击都落在按钮、开关或行上；动作和台词同时发生。
- [ ] 光标在动作之间停住，没有乱晃。
- [ ] 相机推近后都拉回来了，没有停在半截。
- [ ] 至少一半的换页是承接；承接过程中没有上一页的残影。
- [ ] 快速移动的帧有运动模糊，静止帧清晰。

联系表上入场中间态（元素正在飞、正在长）不算缺陷。

## 时间

- [ ] 每个 `at` 都是从 `_words` 查到的关键词时间，没有手敲的近似值。
- [ ] 字幕文字已通读，专有名词没有同音错字。

## 成片

- [ ] 最终 AAC 响度在 −15 到 −14 LUFS，True Peak 不高于 −1 dBTP（量实际 MP4）。
- [ ] 在手机上看过：字幕没有被平台按钮和文案挡住，右侧和底部没有被裁。
- [ ] 同一台设备、同一音量连续听过一遍。
- [ ] 没做的项如实写「待做」。
