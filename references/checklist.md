# 验收清单

配置、动态和接缝检查见 [scheme-d.md](scheme-d.md)。

出联系表（`bash scripts/contact.sh <期名> <秒> …`）后逐项看。渲整片后再过一遍后四项。

## 画面

- [ ] 每屏只有一个焦点。
- [ ] 所有文字不小于 32px；被配音念到的原文，在画面上不小于 32px（字号 × 相机倍数）。
- [ ] 工作台段标题栏的「示意界面」可见。
- [ ] 每个素材都有真实性标签；原文卡片里的字和原文一致。
- [ ] 工作台蓝色表示当前操作；场景蓝色作荧光笔、黑色作强调；橙色只表示问题和行动号召。
- [ ] 背景只有点阵和慢速游走的蓝光；没有贯穿全片的装饰线，没有漂浮圆，没有整屏淡出淡入。
- [ ] 窗口下方约 400px 没有放内容。
- [ ] 大字没有照抄同时的字幕；画面在讲的镜头没有多余大字（v1.2）。
- [ ] 删掉大字的镜头重心还在：没有一大块空着。
- [ ] 文字和卡片标签、来源角标、字幕之间留够距离，长标签没有溢出、没有被别的元素压住。
- [ ] 色块章节卡上的章节名没有出界（四个字用较小字号）。

## 动效

- [ ] 光标每次点击都落在按钮、开关或行上；动作和台词同时发生。
- [ ] 光标在动作之间停住，没有乱晃。
- [ ] 相机推近后都拉回来了，没有停在半截。
- [ ] 工作台内至少一半换页优先承接；过渡无残影，场景切换无叠画面。
- [ ] 大纲完整出现一次，回大纲最多一次；工作台连续约 40–60 秒后适当切回场景。
- [ ] 每段有清晰的变化；没有用慢推、慢呼吸或长时间定格填时长。
- [ ] 快速移动的帧有运动模糊，静止帧清晰。

联系表上入场中间态（元素正在飞、正在长）不算缺陷。

## 时间

- [ ] 每个 `at` 都是从 `_words` 查到的关键词时间，没有手敲的近似值。
- [ ] 字幕文字已通读，专有名词没有同音错字。

## 三道检查

- [ ] 配置检查没有未解决的必须改项；工具未覆盖的字段仍逐镜核对。
- [ ] 实际 MP4 动态检查的异常已核实，必要豁免有时间段和理由。
- [ ] 接缝附近每组 7 个抽样帧已看过；连续播放确认交接与结果动作。
- [ ] ASR 文字正确之外，工具名和句内停顿经过真实试听。

## 成片

- [ ] 最终 AAC 响度在 −15 到 −14 LUFS，True Peak 不高于 −1 dBTP（量实际 MP4）。渲染时音轨会重新编码，常比混音稿低 0.5–1 dB，量完按差值补增益再量一次。
- [ ] 在手机上看过：字幕没有被平台按钮和文案挡住，右侧和底部没有被裁。
- [ ] 同一台设备、同一音量连续听过一遍。
- [ ] 没做的项如实写「待做」。

## 交付

- [ ] MP4、字幕和章节绑定同一最终时间轴，旧版本保留。
- [ ] 按需求提供封面、发布文案、可编辑工程及来源清单。
- [ ] 公开分享包不含私人声纹、凭据与未授权素材。
